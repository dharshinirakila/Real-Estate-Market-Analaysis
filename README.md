# 🏠 Real Estate Market Analysis Dashboard – Power BI

## 📌 Project Overview
This project analyzes real estate property data using Microsoft Power BI.
The dashboard provides insights into property prices, sales trends, 
location-wise analysis, and property types to help users understand 
the real estate market.

## 🎯 Project Objectives
- Analyze property prices across different cities and states.
- Understand property sales trends over time.
- Compare prices based on property types and BHK.
- Identify locations with higher property prices.
- Present key insights through interactive dashboards.

## 🛠️ Tools & Technologies
- Microsoft Power BI
- Power Query
- Data Cleaning
- Data Visualization

## 📊 Dashboard Pages

### 1. Market Overview
Provides an overview of the real estate market with key performance indicators and property details.

### 2. Price & Sales Trend
Analyzes property prices and sales trends over time.

### 3. Location Analysis
Compares property prices across different cities and states.

### 4. Property Insights
Analyzes property types, BHK, area, and price to understand property characteristics.

## 🧹 Data Cleaning
- Cleaned the dataset using Power Query.
- Checked data types and column consistency.
- Prepared the data for visualization and analysis.

## 📈 Key Insights
The dashboard helps users explore property prices, compare locations, 
analyze property types, and understand real estate market trends.
